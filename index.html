Endpoints

GET /recipes HTTP/1.1

Get all recipes

GET /recipes/:id HTTP/1.1

Get a recipe by id

:id is a number

POST /recipes HTTP/1.1

Add a recipe

Json format: { name, ingredients, instructions, username, categoryname }

GET /users HTTP/1.1

Get all users

POST /users HTTP/1.1

Add a user

Json format: { username }

GET /categories HTTP/1.1

Get all categories
