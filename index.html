Recipes API Reference

GET /recipes

Description: Retrieves a comprehensive list of all recipes.

Response Status: 200 OK

Response Body (JSON):

[
  {
    "id": 1,
    "name": "Spaghetti Carbonara",
    "ingredients": "pasta, eggs, pancetta, cheese",
    "instructions": "Cook pasta. Fry pancetta. Mix everything together.",
    "username": "chef_mario",
    "categoryname": "vegan"
  }
]

GET /recipes/:id

Description: Retrieves details of a specific recipe using its unique ID.

URL Parameters:

  • :id (Number, Required) — The unique identifier of the recipe.

Response Status: 200 OK / 404 Not Found

Response Body (JSON):

{ 
  "id": 1,
  "name": "Spaghetti Carbonara",
  "ingredients": "pasta, eggs, pancetta, cheese",
  "instructions": "Cook pasta. Fry pancetta. Mix everything together.",
  "username": "chef_mario",
  "categoryname": "vegan"
}

POST /recipes

Description: Creates and adds a new recipe to the collection.

Request Body (JSON):

{
  "name": "String",
  "ingredients": "String",
  "instructions": "String",
  "username": "String",
  "categoryname": "String"
}

Response Status: 201 Created / 400 Bad Request

GET /users

Description: Retrieves a list of all registered users(chefs).

Response Status: 200 OK

Response Body (JSON):

[
  {
    "id":1,
    "username": "chef_mario",
    "email": "chef_mario@gmail.com"
  },
  {
    "id":2,
    "username": "chef_mior",
    "email": "chef_mior@gmail.com"
  }
]

POST /users

Description: Registers a new user(chef) account.

Request Body (JSON):

{
  "username": "String",
  "email": "String"
}

Response Status: 201 Created / 400 Bad Request

GET /categories

Description: Retrieves a list of all recipe categories available.

Response Status: 200 OK

Response Body (JSON):

[
  {
    "id": "1",
    "categoryname": "vegan"
  },
  {
    "id": "2",
    "categoryname": "vegetarian"
  }
]
